Mobiliteit.lu MCP

An unofficial Model Context Protocol server for Luxembourg public transport data. It is not affiliated with mobiliteit.lu or the public transport administration.

Endpoint

POST /mcp
Authorization: Bearer <token from the operator>

Tools: find_nearby_stops, get_departures. This hosted endpoint is stateless, so live departure subscriptions are only available when you self-host the Node server.

Source, self-hosting guide and API key instructions on GitHub

Health check: /healthz
